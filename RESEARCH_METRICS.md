# Research metrics
Question delivery: client records `performance.now()` at question receipt; server sends `serverTimestamp` at broadcast. For cross-machine accuracy, use server/client clock synchronization or, preferably, measure delivery as a Socket.IO round-trip-derived metric in a controlled client and report the exact method. Answer acknowledgement uses client `Date.now()` immediately before emit and server acknowledgement timestamp returned in the same response; for rigorous cross-host measurement use monotonic RTT timing (`performance.now()`) around the emit/ack callback rather than subtracting unsynchronised wall clocks.
Throughput = successful answer events / test duration. Error rate = failed events / total events * 100. Record EC2 CPU and memory from CloudWatch/OS monitoring using the same sampling method for every run.
Required runs: 10,25,50,100 users; same quiz/configuration; only concurrency changes. Export actual average, median, P95, throughput, error rate, CPU and memory.
